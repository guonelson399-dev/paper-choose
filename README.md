# Paper Choose：机翻后，只改你选中的地方

**英文论文 → Argos 中文机翻 → 对照英文核对 → 你选择修改 → 下载结果。**

你已经有一份英文论文，想翻成中文，又不希望 AI 顺手改掉意思。Paper Choose 保留英文原稿，让 AI 找出机翻中的必要错误，再由你逐项决定要不要改。没有选中的地方保持原样。

当前版本：`2.1.0-dev.3+base44.1`，开发候选版。新界面由作者提供的 Base44 项目整合而来。

## 第一次怎么打开？

1. 点击本页绿色 **Code → Download ZIP**，下载后右键 **全部提取**。不要直接在压缩包里运行。
2. 打开解压后的项目文件夹。你应能看到 `start_windows.cmd`、`paperchoose` 和 `frontend`。
3. 准备 Python。翻译组件使用 Python **3.10–3.12，建议 3.12**。已有这个版本就不用重装；安装入口见 [INSTALL.txt](INSTALL.txt)。
4. 想在页面直接翻译，先双击 `setup_local_translation.cmd`。它会询问是否下载依赖和模型，安装完成后显示 Done。已有译文可以跳过这一步。
5. 双击 **start_windows.cmd**，保持弹出的终端窗口打开。浏览器会打开 `http://127.0.0.1:8765/`。

这是你电脑上的页面。别人打开同一个地址不会看到你的稿件。下载包已包含构建好的网页，普通使用者不需要安装 Node.js 或重新打补丁。

## 一篇稿件怎么处理？

1. **放入稿件**：左边粘贴英文原稿。右边可以粘贴已有中文机翻，也可以点“用本机 Argos 翻译”。英文原稿始终是依据，不要求先确认中文。
2. **核对设置**：可以填写术语的准确写法，也可以让 AI 在核对时一起识别。确认允许发送英文原稿和中文机翻稿后，点击“开始核对”。
3. **逐条选择**：看每条建议的英文依据、改前改后和原因。默认都不采用；只点你认可的修改。
4. **导出结果**：下载结果包，其中原稿、原始机翻稿、修改结果、差异和采用记录分别保存。全部不采用时，新稿与机翻稿相同。

可以先点击“载入一份演示稿”熟悉流程。演示中文是人工编写、故意带错的模拟机翻；如果点击核对，仍会请求实际配置的云端 AI。

## 翻译与核对在哪里运行？

| 操作 | 在哪里运行 |
| --- | --- |
| Argos 翻译 | 你的电脑 |
| AI 找出翻译错误 | 配置的 Base44 云端服务，点击同意并开始核对后发送稿件和术语 |
| 校验建议、执行选中的修改、导出 | 你的电脑 |

本地服务不自动保存稿件；云端处理和留存遵循服务提供方政策。关闭或刷新网页会丢失未下载的内容和翻译进度。仅放入你允许处理的材料。

源码中的 Base44 应用 ID 是作者提供的连接配置，不是密钥。**公开源码不代表向所有下载者承诺免费的云端服务**；是否可用取决于该应用的发布、访问权限和额度。本轮没有重新部署 Base44 云端函数。自建服务见 [前端部署说明](frontend/部署说明.md)。

## 为什么还有长度限制？

- **翻译**：单次请求最多 5000 字符。新页面会自动按段落或句子分批，按顺序合并，原稿不必手动拆成 5000 字符。失败后可在当前页面继续未完成批次；刷新后不能恢复。
- **AI 核对**：当前一次接受英文和中文各 **15000 字符**。这是本应用的核对配置，不是 Argos 的限制。超过时明确提示按章节核对，不会偷偷截断。暂未实现整篇自动分批核对。
- 字符不是单词，包含空格和标点。当前输入为纯文本，不保留 Word/PDF 排版。

## 遇到问题

| 情况 | 怎么处理 |
| --- | --- |
| 页面打不开 | 完整解压，再双击 start_windows.cmd；保持终端打开 |
| 显示模型未安装 | 运行 setup_local_translation.cmd；也可直接粘贴已有译文 |
| 翻译过程中改了稿件 | 旧翻译停止；用当前原稿重新翻译 |
| 建议不能采用 | 看提示：可能位置不唯一、与另一项重叠、或违反了保护要求 |
| 原稿、机翻稿或设置变了 | 为新输入重新核对，不能套用旧建议 |
| 云端核对不可用 | 检查服务配置和权限；可用下方的助手/原界面入口 |

## 已有 AI 助手的用户

原有 Skill、命令行和手动导入建议仍保留。打开 `http://127.0.0.1:8765/classic` 可进入原界面；其操作见 [原界面说明](docs/CLASSIC_WORKBENCH.md)。让有文件和命令权限的助手读取 [SKILL.md](SKILL.md) 与 [AGENT_WORKFLOW](docs/AGENT_WORKFLOW.md)。这些入口保留双向核对能力，新网页聚焦英文原稿→中文机翻。

## 开发者

- `frontend/`：可维护的 Base44 前端、云端函数和锁定依赖。
- `paperchoose/webapp/`：由前端源码构建、供 Python 本地服务直接打开的网页。
- `paperchoose/workflow.py`：输入绑定与作者择项修改；新旧界面共用这一份执行器。
- `paperchoose/translation.py`：Argos 本地翻译。

重建网页：在 `frontend` 目录执行 `npm ci`、`npm run build:local`，然后执行 `python ../scripts/install_webapp.py`。

验证：项目根目录执行 `python -B -m unittest discover -s tests -v`；在 `frontend` 执行 `npm test`、`npm run lint`、`npm run build:local`。测试覆盖和未完成检查见 [发布状态](docs/CANDIDATE_STATUS.md)。

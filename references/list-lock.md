# 作者选择锁定

只有当前列表中被作者选中的P1/P2编号可以执行。原文必须精确匹配，重复出现时用章节、段落和相邻文字唯一定位。重叠建议或相互冲突的选择先请作者确认，不自行决定。

P1-all、P2-all仅指当前已展示的对应清单。apply none不作修改；导出副本的正文与717稿一致。其他情况下，未选项及相邻文字保持原样。

原稿、717稿、术语、作者说明或建议发生变化后，重新核对受影响的建议并重新取得选择，不沿用旧编号的授权。执行阶段不新增修改或猜测作者意思。

执行后对照输入稿与修改稿：每处差异都应对应已选编号；无关文字不得改变。保留两份输入，导出修改稿及简短前后对照。无法验证的格式或位置问题需说明，不声称已完整验证。

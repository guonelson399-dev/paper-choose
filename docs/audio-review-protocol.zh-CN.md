# 音频校对扩展规则（设计稿）
 
状态：规则与合成案例；尚未接入当前网页、命令行或语音引擎。记录日期：2026-10-21（Asia/Shanghai）。
 
## 要帮用户完成什么
 
把录音转成文字后，找出可能听错的术语、数字、否定词和要求；给出有位置、有理由的局部建议，由用户选择是否采用。保留粤语夹杂英语的表达，翻译和总结另存。
 
音频是独立组件。Paper Choose 在这里提供作者控制修改的规则；当前英文原稿→中文机翻的论文流程保持不变。本文没有新增可调用接口，案例 JSON 也不是现有 translation_audit v2 的输入。
 
## 依据与材料
 
1. 原始录音用于核对说话内容。不得用课件、常识或 AI 总结覆盖实际讲话。老师的口误也不能悄悄改成“正确原话”，知识解释应另列。
2. 原始自动转写、经用户修改的校对稿、翻译/摘要、项目决定分别保存。原始录音与转写不覆盖。
3. 术语可由用户手动添加，也可由 AI 从本次获准使用的课件/论文中提取，二者可结合。记录出处、页码或段落；没有可靠位置就写未知。只给当前片段相关的小词表，不需建立全学科数据库。
4. 区分作者明确指定的保护要求与 AI 提取的候选。课件出现某词只支持候选，不能证明录音说过这个词。英文术语与中文解释分开保存。
 
## 拟议处理过程
 
1. 以转写模式取得带时间戳的初稿，尽量保留粤英混说，不先翻译或自由润色。记录实际引擎、模型、参数及时间戳来源。
2. 根据识别分数、术语疑点、重复表达不一致或多次识别分歧，列出可疑片段。分数不是校准后的正确概率；高分也可能错。数字、日期、否定和“建议/必须”优先核对。
3. 仅对疑点连同适量前后文重新识别，可使用课件词表，必要时比较另一引擎。不得按单词强行切断粤英混说。两个模型一致也不等于原话已验证。
4. Agent 负责找材料、选择复核片段并提出建议。只收到文字的模型必须标明未听音频，不能声称音频核验通过。
5. 展示原识别、最小替换、原因、材料出处、回听位置和证据状态。没有音频/时间戳时只能定位文字段落，不伪造秒数。
6. 等待用户选择；未选择保持原样。生成新校对稿、精确差异和采用记录；尚未确认事项单独列出，不自动生成确定截止日或执行任务。
 
## 修改执行约束（待实现与测试）
 
- 默认不选择。仅应用本轮明确采用的建议；全部不采用时输出保留原始转写字节，包括空格和换行。
- 每条建议绑定音频摘要、转写摘要、术语/保护设置版本，以及具体文字跨度与上下文。同词多次出现不能做全局替换。
- 音频、更正稿或设置变化后，旧建议和旧选择失效，重新核对。摘要绑定版本，不认证语义或作者身份。
- 重叠修改不能同时应用；指定保护内容与建议冲突时先处理冲突，再重新取得选择。
- 证据状态与作者决定分开记录。作者可接受尚未音频核实的候选，但记录仍写“作者采用、音频未核实”，不能自动升级为事实；日期/否定等关键歧义应提示回听或明确人工确认。
- 听不清允许保留待确认，不补写不存在的词。没有完成核对不能标成“零问题”。
 
## 简单例子（全部为合成文字，无对应录音）
 
| 情况 | 应如何处理 |
| --- | --- |
| 呢个係 overfitting，唔代表可以 generalize。 | 保留混说和否定；书面中文另存 |
| almost good faith；课件写 utmost good faith | 提出术语候选，回听后由用户决定 |
| 需要交 / 唔需要交 两次识别不同 | 标出分歧，不能凭常识补否定 |
| 课件写 20%，转写写 30% | 保留差异；核对是否老师更新、口误或识别错误 |
| 可以考虑加 regression | 保留建议强度，不能生成必须运行模型的任务 |
| 只采用术语 A、不采用数字 B | 只改 A；B 原样保留并继续标为待确认 |

## 给执行 Agent 的任务说明
 
使用本次用户允许处理的材料。先记录你实际拿到的是音频、转写还是课件，说明是否能听音频。
保留原始文件，提取带出处的少量术语候选。只列可能影响原意的局部疑点，不全文润色。
若能运行获准的语音引擎，对疑点片段重新识别；否则明确标为文字推测。
逐条展示修改编号、前后文本、回听位置或段落、证据与待确认事项，等待作者选择。
不得把现有翻译接口冒充音频接口；当前仓库尚未提供这一执行链。
 
## 本地与云端权限
 
原始音频默认本地处理。音频片段、转写文字、课件分别按用户允许的范围处理；允许发送文字不等于允许上传录音。调用云端前说明目的地与发送范围。导入文本不要求用户改用某个转写软件。
 
公开仓库只放合成或明确获准公开的案例，不放课堂录音、真实转写、教师邮件或名单。当前案例不含上述材料。

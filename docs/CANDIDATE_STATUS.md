## 实测与模拟的区别

`tests/test_translation.py` 的翻译引擎使用明确标记的测试替身，检验边界和 HTTP 行为。
`examples/synthetic/translation-smoke.json` 才是真实 Argos 的合成文本结果，列出实际版本与模型归档摘要。
真实 HTTP 导出检查采用空修改清单，只检验传输、版本绑定和“不修改”导出，未声称完成 AI 语义审阅。
JS 检查运行在 Node 的 DOM/状态模拟中，不等于真浏览器验收。

实测使用 Argos Translate 1.9.6、CPU PyTorch 2.5.1、CTranslate2 4.8.3、Stanza 1.1.1、SentencePiece 0.2.0、protobuf 3.20.3，中英双向模型均为 1.9。

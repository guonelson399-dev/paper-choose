Paper Choose 本地翻译候选版 2.1.0-dev.1+localmt.3

先解压整个 paper-choose 文件夹，再打开 README.md。
基础功能：安装 Python 3.10 或更新版本，双击 start_windows.cmd。
可选本地翻译：使用 Python 3.12，双击 setup_local_translation.cmd。
安装器联网下载依赖与双向模型，不读取稿件。安装后重启工具。
在页面使用“中文 → 英文”或“英文 → 中文（阅读草稿）”。
先预览译文，再选择采用。采用后要为新版本重新核对。
AI 核对由当前助手完成；有文件与命令执行权限的助手可读取 docs/AGENT_WORKFLOW.md 跑整条链，不需另开 API。
单独使用网页时仍需导出请求并导入建议。
原稿不被覆盖，关闭页面前请保存译文、采用记录和结果。
Windows 安装器尚未实机验证。更详细说明及已做检查见 README.md。
